# Data Visualisation & Storytelling

A collection of data science projects and interactive visualizations developed during my studies at the University of Texas at San Antonio (UTSA). This repository focuses on transforming raw data into actionable insights through Python-based analysis and visual storytelling.

## Projects Included

### 1. World GDP & Population Analysis
An exploratory analysis of global economic trends. This project uses Python to visualize the relationship between a nation's population growth and its economic output.
* **Key Tools:** Pandas, Matplotlib, Seaborn
* **Focus:** Identifying correlation patterns between demographic shifts and GDP.

### 2. Sentiment Analysis (Work in Progress)
A project exploring natural language processing (NLP) to categorize public sentiment from text data.
* **Key Tools:** Python, NLTK
* **Focus:** Data cleaning for text and basic classification.

## How to Explore
1. **Clone the repository:**
   `git clone https://github.com/mkalkidan/Data_Visualisation.git`
2. **Install dependencies:**
   Make sure you have Python installed, then install the required libraries:
   `pip install pandas matplotlib seaborn`
3. **Open the Notebooks:**
   Navigate to the project folders and open the `.ipynb` files in Jupyter or VS Code to see the code and visualizations.
